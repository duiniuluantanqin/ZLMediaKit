# SVG 图标说明

本目录包含了视频监控系统使用的所有SVG图标文件。

## 图标列表

| 文件名 | 描述 | 用途 |
|--------|------|------|
| `volume-on.svg` | 音量开启图标 | 视频控制按钮、音量控制 |
| `volume-off.svg` | 音量关闭/静音图标 | 静音状态显示 |
| `record.svg` | 录像图标 | 开始录像按钮 |
| `stop.svg` | 停止图标 | 停止录像、停止连续抓图 |
| `camera.svg` | 相机图标 | 抓拍按钮 |
| `close.svg` | 关闭图标 | 关闭视频窗口 |
| `arrow-right.svg` | 右箭头图标 | 右键菜单子菜单指示 |

## 设计规范

- **尺寸**: 所有图标基于 24x24 像素的 viewBox 设计
- **颜色**: 使用 `fill="currentColor"` 以支持动态颜色变化
- **风格**: 简洁的线条风格，符合现代UI设计
- **兼容性**: 支持所有现代浏览器

## 颜色主题

系统使用两种主要颜色：
- **白色** (#FFFFFF): 用于悬浮控制按钮
- **青色** (RGB 0,186,173): 用于布局控制、激活状态等

## 使用方式

图标通过以下方式在HTML中使用：

```html
<img class="icon-svg" src="./icons/volume-on.svg" alt="音量开启">
```

CSS样式会自动应用正确的颜色滤镜。

## 技术实现

- 使用CSS `filter` 属性来改变图标颜色
- 页面加载时自动替换内联SVG为外部文件引用
- 支持动态图标切换（如音量开/关状态）
